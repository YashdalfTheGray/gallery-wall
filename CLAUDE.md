# Claude instructions

Read [AGENTS.md](AGENTS.md) for project context and the rule file index.

Write all documentation in ASD-STE100 (STE-100). Write as a technical author. Do not write marketing prose.

Use short sentences. Use one idea per sentence. Use the active voice. Use imperative verbs for procedures (for example: "Run the test."). Use approved STE words when a simpler word exists in the STE dictionary. Do not use slang, idioms, or figurative language.

Do not insert forced line breaks in prose. Write each paragraph as continuous text. Do not wrap lines at a fixed column width. Use blank lines only between blocks (headings, paragraphs, lists, tables, code fences).

State facts. Do not over-emphasize. Do not use excessive bold, italics, or ALL CAPS. Do not use labels such as "Important", "Note", or "Warning" unless the document type requires them (for example: safety warnings).

This applies to README files, AGENTS.md, CLAUDE.md, docs/, .cursor/rules/, godoc prose, commit messages that document behavior, and user-facing UI copy in documentation.
